# VRChat Recap

VRChat 스크린샷 폴더를 사진 중심의 개인 Recap으로 바꾸는 웹 앱입니다.

## 경험

- 원본 사진, 실제 월드 이름, 실제 닉네임을 시간순으로 보여줍니다.
- 사진이 많은 경우에도 현재 사진과 발견되는 이름·월드·둘만의 순간을 계속 표시합니다.
- 메타데이터에서 가장 자주 등장하는 닉네임을 사용자 본인으로 판단합니다.
- 사용자와 다른 한 명만 기록된 사진을 모아 특별한 사람과의 추억을 구성합니다.
- 한국어, 영어, 일본어를 지원하며 언어를 바꿔도 사진을 다시 처리하지 않습니다.
- 마지막 장에서 주요 통계와 대표 사진 네 장을 16:9 종합 카드로 보여주고 PNG로 저장합니다.

## 사진 정보가 부족한 경우

PNG 메타데이터가 있으면 월드와 닉네임을 그대로 사용합니다. 사진의 사람 정보가 없을 때는 브라우저 안에서 반복해서 나타나는 얼굴의 흐름을 보완적으로 묶습니다. 해당 처리를 사용할 수 없는 환경에서는 메타데이터와 날짜만으로 Recap을 계속 만듭니다.

## 실행

```bash
pnpm install
pnpm run dev
```

```bash

pnpm run lint
pnpm run test
```
