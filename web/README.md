# VRChat Recap + Memory Walk

VRChat 스크린샷 폴더를 개인 통계 리캡과 자동 횡스크롤 기억 산책으로 바꾸는 로컬 우선 웹 앱입니다. 리캡은 `/`, 기억 산책은 `/game`에서 각각 독립적으로 열립니다.

## 지금 할 수 있는 것

- Chrome/Edge의 폴더 선택기 또는 `webkitdirectory` 폴백으로 중첩된 스크린샷 폴더를 재귀적으로 엽니다.
- PNG 촬영 시각을 우선 사용하고, 파일명 날짜와 수정 시각을 차례로 폴백합니다.
- 모든 사진을 한 장씩 내장 EfficientDet Lite0 모델과 48×27 색상 분석기로 처리합니다. 모델은 사람·동물형 아바타 후보를 찾고, 16×9 캔버스는 12-bit RGB 기억층과 밝기·채도·윤곽 지문을 만든 뒤 비트맵을 즉시 닫습니다.
- 4시간 이내의 사진을 한 세션으로 묶고 최대 64개 기억 챕터로 합칩니다. 합쳐진 챕터에도 그 시기의 모든 사진 색상과 메타데이터가 반영됩니다.
- 사진 수, 활동일, 세션, 최다 촬영일, 시간대, 계절, 실제 월드, 반복 동행자와 전수 분석 상태를 9장 리캡으로 보여 줍니다.
- 서로 다른 인스턴스 3회 이상이면서 서로 다른 날짜 2일 이상 함께한 이름만 반복 동행자로 표현합니다. 아바타가 달라져도 PNG의 VRChat 사용자 ID가 같으면 한 사람으로 합치고, 로컬 모델이 뒷받침한 장면 수를 별도로 표시합니다.
- 현재 아바타 이미지 한 장을 브라우저 안에서 배경 분리·저해상도 재구성·12-bit 양자화해 4×3 걷기 스프라이트 시트로 새로 만듭니다. 기존 캐릭터 몸에 얼굴이나 사진을 끼워 넣지 않습니다.
- 기억 산책은 자동으로 오른쪽으로 흐릅니다. 점프, 발판, 충돌, 실패, 클리어 조건은 없으며 일시정지·속도·설명 표시만 조절합니다.
- 아홉 개 전용 픽셀 아트 환경에 각 시기의 16×9 기억층을 합성하고, 장면 속 픽셀 엽서에는 그 시기 사진들의 실제 색상 구도를 더 선명하게 보여 줍니다.
- 현재 공개 샘플은 로컬 사진 4,986장 전부를 9개 시대의 16×9·12-bit 평균 기억 색상으로만 집계한 결과입니다. 원본 픽셀, 파일명, 월드 이름, 플레이어 이름은 포함하지 않습니다.
- 사진을 포함하지 않는 1200×630 리캡 카드와, 파일명·원본 픽셀·사용자 ID가 없는 압축 기억 인덱스 JSON을 저장할 수 있습니다.

## 개인정보 원칙

사진과 아바타 이미지는 브라우저 밖으로 전송되지 않습니다. MediaPipe 실행 파일과 EfficientDet 모델도 사이트의 same-origin 정적 자산으로 포함되어 있어 사진 업로드 API, 분석 서버, 추적, 외부 AI 호출이 없습니다. 원본은 저장소나 세션 저장소에 넣지 않으며 새로고침하면 로컬 파일 연결이 사라집니다.

앱은 사진을 건너뛰지 않되 동시에 여러 원본을 열지 않습니다. 한 번에 한 장만 작은 해상도로 디코딩하고 즉시 닫아 4천 장 이상에서도 작업 메모리가 원본 수에 비례해 늘어나지 않게 했습니다. 게임으로 넘기는 값은 최대 64개 챕터의 메타데이터, 16×9×12-bit 기억층, 로컬에서 만든 아바타 스프라이트뿐입니다.

## 친구와 월드 표현

로컬 모델은 사진에 사람·동물형 아바타 후보가 있는지만 판단하며 얼굴 특징이나 생체 템플릿을 만들지 않습니다. “누구인지”는 VRChat이 PNG에 기록한 안정적인 사용자 ID로 연결하고 촬영자 자신은 제외합니다. 여러 후보 중 특정 사람이라고 단정할 수 없는 장면은 AI 근거로 세지 않습니다. 반복 동행자는 해당 기억 챕터가 끝날 때까지 주인공 옆을 함께 걸으며, 그 밖의 우연한 동석자는 이름 없는 메아리로 장면에 머뭅니다.

로컬 모델 선택과 보수적인 사용자 연결 기준은 [docs/local-model-evaluation.md](docs/local-model-evaluation.md), 리캡 구조 결정은 [docs/recap-product-decisions.md](docs/recap-product-decisions.md)에 정리했습니다.

## 브라우저 지원

최신 Chrome/Edge가 가장 좋습니다. 폴더 선택 API가 없으면 숨겨진 다중 파일 입력을 사용합니다. HEIC처럼 브라우저가 디코딩하지 못하는 형식은 날짜에는 포함되지만 기본 지문으로 대체될 수 있습니다.
