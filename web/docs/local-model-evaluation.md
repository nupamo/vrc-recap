# 로컬 인물 모델 설계

## 결론

기본 분석기는 **MediaPipe Object Detector + EfficientDet Lite0 (uint8)** 입니다. 실행 파일과 약 4.6MB 모델을 모두 `public/` 아래의 same-origin 자산으로 제공하며, 선택한 사진은 업로드하지 않습니다. 브라우저는 한 번에 한 장만 최대 너비 640px 비트맵으로 열고 추론 직후 닫습니다.

이 모델이 담당하는 일과 VRChat 메타데이터가 담당하는 일은 의도적으로 분리했습니다.

- 로컬 모델: 사진 안에서 사람·동물형 아바타로 볼 수 있는 시각 후보를 찾습니다.
- PNG 메타데이터: 월드, 인스턴스, 함께 있던 플레이어의 표시 이름과 안정적인 VRChat 사용자 ID를 읽습니다.
- recap 집계: 동일한 사용자 ID는 아바타 외형이 달라져도 한 사람으로 합칩니다.

아바타 외형만으로 사람의 신원을 추정하지 않습니다. VRChat에서는 한 사람이 전혀 다른 인간형·동물형·비인간형 아바타로 바뀔 수 있으므로, 이미지 임베딩으로 신원을 고정하는 방식보다 사용자 ID가 정확하고 설명 가능합니다.

## 보수적인 시각 근거 규칙

PNG의 플레이어 목록은 “같은 인스턴스에 있었다”는 뜻이지 반드시 사진에 찍혔다는 뜻은 아닙니다. 그래서 다음 조건에서만 특정 반복 사용자에게 `AI 근거 장면`을 더합니다.

1. 로컬 모델이 사진에서 아바타 후보를 하나 이상 감지합니다.
2. 촬영자를 제외한 동석자가 한 명뿐이거나, 감지된 후보 수가 동석자 수 이상입니다.
3. 사용자는 서로 다른 인스턴스 3회 이상, 서로 다른 날짜 2일 이상 함께 있어야 recap의 반복 동행자 후보가 됩니다.

여러 명 중 일부만 보이는 모호한 단체 사진은 특정 사용자의 AI 근거로 세지 않습니다. AI 근거가 0장이어도 메타데이터상 반복 조건을 만족한 사용자는 표시하되, UI에서 근거 수를 그대로 보여 줍니다.

## 모델 범위와 한계

EfficientDet Lite0는 일반 객체 데이터로 학습됐기 때문에 VRChat의 극단적인 비인간형 아바타를 놓칠 수 있습니다. 이를 조금 완화하기 위해 `person`뿐 아니라 `cat`, `dog`, `bird`, `horse`, `sheep`, `bear`, `teddy bear` 범주의 감지도 아바타 후보로 취급합니다. 이것은 신원 판정이 아니라 사진 안의 시각적 주체가 있다는 보조 근거입니다.

모델 초기화가 불가능한 브라우저에서는 색상 분석과 PNG 메타데이터 recap은 계속 생성하고 `LOCAL MODEL OFF`, `AI PASS 0`을 표시합니다. 모델 결과를 임의의 이름으로 바꾸거나 실패를 성공처럼 표시하지 않습니다.

## 개인정보와 메모리 경계

- 모델과 WASM은 외부 CDN이 아닌 사이트 자체 경로에서 읽습니다.
- 원본 픽셀, 얼굴 특징, 감지 상자, 임베딩은 저장하지 않습니다.
- 영구 결과에는 모델 처리 장수, 아바타 후보가 있던 장면 수, 총 감지 수, 반복 사용자별 보수적 근거 장수만 남습니다.
- 사용자 신원 연결에는 PNG의 VRChat 사용자 ID를 메모리 안에서만 사용하며, 내보내는 압축 기억 인덱스에는 사용자 ID를 포함하지 않습니다.
- 모델용 비트맵과 16×9 색상 분석 비트맵은 각 사진 처리 직후 닫습니다.
